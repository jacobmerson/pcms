# splines-eqdsk

A tokamak equilibrium from an EQDSK file as a spline field. The file gives the
poloidal magnetic flux psi(R, Z) on a uniform grid; PCMS makes a bicubic
spline space on that grid, smooth enough to differentiate, and the gradient of
psi is the poloidal magnetic field (`B_R = -(1/R) dpsi/dZ`, `B_Z = (1/R)
dpsi/dR`). The example reads the file, finds the magnetic axis by Newton's
method on the gradient, samples a flux surface by bisection along 64 rays
from the axis (one batched evaluation per step), and checks the field.

The file `solovev.eqdsk` (17 kB, 25 x 33 points) is generated by
`make_eqdsk.py` from an analytic Solov'ev equilibrium, `psi = psi_axis + A
(R^2 - R0^2)^2 + B Z^2`, which solves the Grad-Shafranov equation; the
example can therefore compare everything with the exact answer. Run
`python3 make_eqdsk.py solovev.eqdsk` to regenerate it.

Asserted: the magnetic axis is at (R0, 0) (1e-4) and psi there is the
`psi_axis` of the file (1e-7); the poloidal field from the spline gradient is
within 1e-4 of the exact one (measured 6e-6) at 36 probe points; the points of
the flux surface have the target psi to 1e-9 and the outboard one the exact
radius to 1e-5; the divergence of the poloidal field, from differences of the
spline gradient, vanishes on the surface to 1e-8 (measured 7e-12).

## Public API used

- `MakeEQDSKField` (`pcms/field/eqdsk_field.hpp`), `EQDSKData` (grid, `PSIZR`,
  `psi_grid`, accessors)
- `CreateSplineSpace`, `backend::uniform_grid::CreateUniformGridGeometry`,
  `csys::CylindricalRZ` (Python: `create_spline_space`,
  `create_uniform_grid_geometry`, `csys.CylindricalRZ`)
- `QueryPoints::Evaluate` with `DifferentialOperator::Gradient`;
  `ValueBasis` with `values::Covector` for the output
- `FunctionSpace::CreateFunction`, `Field::SetDOFHolderData`

## Run

```console
$ ctest -R example.fields.splines-eqdsk
$ build/examples/fields/splines-eqdsk/fields_splines_eqdsk examples/fields/splines-eqdsk/solovev.eqdsk
$ PYTHONPATH=build/src/pcms/pythonapi python3 examples/fields/splines-eqdsk/main.py examples/fields/splines-eqdsk/solovev.eqdsk
```

## What to look at

The gradient is evaluated like the field, with an output tagged as a covector;
asking for it with a scalar tag is refused. The axis is found in one Newton step
because the spline gradient is exact at the grid nodes for this psi, and the
poloidal field on the flux surface (up to 1.45 in the units of the file)
comes straight from it.

## TODO: gaps of the API

- The Python API has no EQDSK reader (`MakeEQDSKField`, `EQDSKData`). The
  Python version parses the file itself (`read_eqdsk` in `main.py`, about
  twenty lines) and creates the spline space from the grid. Bind the reader and
  replace `read_eqdsk`.
- `MakeEQDSKField` returns a `Field`, which cannot be evaluated (the header
  has a TODO to return a `Function`); the C++ version copies its values to
  a `Function` of the returned space. Return the `Function` and drop the copy.
- `EQDSKData` does not keep the magnetic axis (`rmaxis`, `zmaxis`) and the
  boundary of the file, which the readers skip; the example finds the axis
  itself. `psi_grid` gives psi at the axis and at the boundary.
